# Friedenslicht-Marathon Ried im Traunkreis

Öffentliche Veranstaltungswebsite für den Friedenslicht-Marathon am 13. Dezember 2026.

## Lokal ansehen

`index.html` direkt im Browser öffnen. Die Website ist statisch und benötigt keinen Build-Schritt.

## Veröffentlichung

Das Repository ist für GitHub Pages aus dem Branch `main` und dem Stammverzeichnis vorbereitet.

## Inhaltlicher Stand

Strecken und Ablaufzeiten aus 2025 sind als vorläufig gekennzeichnet. Online-Anmeldung und veranstaltungsbezogene Kontakte werden ergänzt, sobald sie für 2026 freigegeben sind.
