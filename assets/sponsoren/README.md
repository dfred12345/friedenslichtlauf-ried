# Sponsorenlogos einfügen

1. Logodatei in diesen Ordner hochladen, am besten als PNG oder WebP ohne Leerzeichen im Dateinamen.
2. In `sponsoren.csv` eine Zeile ergänzen:

```text
Firmenname;https://www.beispiel.at;beispiel-logo.png
```

Nach dem Speichern erscheint das Logo automatisch auf `sponsoren.html`. Ist die Bilddatei nicht vorhanden, wird stattdessen der Firmenname angezeigt.
